# Sharepoint

Sharepoint is a Fabric mod for Minecraft that makes it easy to share Lunar Client waypoint files between players or across devices through a simple in-game interface. It can also sync waypoint data automatically, making it easier to keep shared waypoint sets up to date without manual file transfers.

## What this mod does

The goal of Sharepoint is to simplify the process of moving and distributing Lunar waypoint data:

- Share a waypoint file with another player through a simple interface
- Automatically sync waypoint data when enabled
- Reduce the friction of transferring Lunar client waypoint files manually
- Keep waypoint sharing straightforward and easy to use in-game

## Features

- Simple waypoint sharing interface
- Automatic waypoint transfer support
- Compatibility with Lunar Client waypoint files
- Designed for Fabric-based Minecraft setups
- Lightweight workflow focused on sharing waypoint data quickly

## Why use Sharepoint?

If you and your friends use Lunar Client waypoints, moving them around manually can be annoying and error-prone. Sharepoint gives you a dedicated tool to handle that process more cleanly, whether you want to:

- send a waypoint file to someone once
- keep a shared waypoint pack in sync
- avoid manual file copying and editing

## Installation

1. Install Fabric for your Minecraft version.
2. Download the latest Sharepoint mod jar.
3. Place the jar in your Minecraft `mods` folder.
4. Launch the game with Fabric enabled.
5. Open the mod interface in-game and begin sharing or syncing waypoints.

Note: Make sure you are using a compatible Fabric and Minecraft version combination for the mod build you download.

## Usage

### Manual sharing

Open the Sharepoint interface from the in-game menu or the relevant mod entry point, then:

- choose the waypoint file to share
- select the target user or transfer method supported by the mod
- send the file through the interface

### Automatic sharing / syncing

If automatic mode is enabled, the mod can watch for waypoint updates and forward them without requiring repeated manual transfers.
